# 🚀 Build2gether

A full-stack web application where users can collaborate and build projects together.

---

## 📌 Features

* 🔐 User Authentication
* 👥 Collaboration system
* ⚡ Fast frontend with Vite + React
* 🌐 Backend using Node.js & Express

---

## 🛠️ Tech Stack

**Frontend:**

* React
* Vite
* Tailwind CSS

**Backend:**

* Node.js
* Express.js

**Other:**

* Git & GitHub

---

## 📂 Project Structure

```
buildtogether/
 ├── buildtogether-client/
 └── buildtogether-server/
```

---

## ⚙️ Installation

### 1️⃣ Clone the repo

```bash
git clone https://github.com/your-username/buildtogether.git
cd buildtogether
```

### 2️⃣ Install dependencies

**Client:**

```bash
cd buildtogether-client
npm install
```

**Server:**

```bash
cd ../buildtogether-server
npm install
```

---

## ▶️ Run the project

**Start backend:**

```bash
cd buildtogether-server
node index.js
```

**Start frontend:**

```bash
cd buildtogether-client
npm run dev
```

---

## 🔑 Environment Variables

Create a `.env` file in both client and server:

```
PORT=5000
```

(And add your API keys if needed)
